# Chrome 扩展 0.4.1：手动播放与全屏退出修复

此更新仅涉及 Chrome 扩展，兼容现有 0.4.0 电脑助手和 iPhone App，无需重装助手或重签 IPA。

## 修复内容

- 旧版本误将播放器“自动开播”当作“播完自动连播”关闭。这是网页持久化设置，会影响之后手动打开的视频。现在只接管明确的下一条连播开关，保留自动开播偏好。
- 遥控全屏采用网页全屏，保留浏览器标签栏，不再叠加浏览器全屏。支持 Esc 和网页退出按钮；移除无退出入口的 CSS 全屏兜底。
- 手动切换视频或分 P 时释放旧队列。加载中的旧播放指令会取消，避免跳到新视频后继续接管。
- 退出遥控队列后，刷新网页不再重新绑定旧队列。

## 更新方法

1. 将 `BiliRemote-Chrome-0.4.1.zip` 解压并覆盖 Chrome 当前加载的扩展目录。开发环境可直接使用构建后的 `extension/dist`；也可在扩展详情中查看“加载来源”确认旧目录。
2. 在 `chrome://extensions` 对“哔哩遥控 · Bili Remote”点击重新加载，确认版本为 **0.4.1**，然后刷新已打开的 B 站网页。
3. 在播放器设置中重新打开 **自动开播**。这是对旧版本残留设置的一次性恢复，新版本不会再次关闭它。
4. 若窗口还留在旧版本的浏览器全屏中，按一次 **F11** 恢复浏览器窗口，再正常使用播放器。

## 验证

- TypeScript 类型检查、扩展构建。
- DOM / 后台回归测试覆盖自动开播偏好、连播设置恢复、手动换视频与分 P、等待播放取消、队列结束去重、网页全屏退出、Esc 与网站事件共存，以及不再调用浏览器窗口全屏。
- 在现有 Chrome 网页中确认旧选择器实际匹配“自动开播”，且该设置已被关闭。浏览器工具不允许打开扩展管理页面，因此未代替用户重新加载扩展；安装后仍需现场验收。
