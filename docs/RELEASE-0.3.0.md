# 0.3.0 安装与使用

本次更新包含 Siri、查看 / 发表评论、收藏夹、UP 主资料与投稿浏览、Apple Watch 配套控制，以及播放列表封面自动补齐。

## 这台电脑的更新

- Windows 助手已更新到 `E:\BiliRemote`，版本 0.3.0，已重启并确认 Chrome 连接。
- 扩展 0.3.0 文件位于 `E:\BiliRemote\extension`。在 Chrome 地址栏输入 `chrome://extensions`，开启开发者模式，找到“哔哩遥控”并点击重新加载，再刷新 B 站页面。确认版本为 0.3.0，并接受扩展所需的新权限。
- 更新保留现有配对。旧助手和扩展备份于 `E:\BiliRemote\backup-player-20260919-180318`。

## iPhone 和 Apple Watch

IPA 是 iOS 17+ 真机 arm64 包，内含 watchOS 10+ 配套应用，未包含个人签名证书或描述文件。需要先签名再安装；签名工具必须同时处理 Watch 子应用，并保持 `WKCompanionAppBundleIdentifier` 与手机 Bundle ID 一致。

交付文件为 `BiliRemote-0.3.0-unsigned.ipa`，源码提交 `a576977`。SHA-256：`1258bd2f4a54f3d5bb762efd0c4afd50842d82ff92629defd3349eda5f2980f4`。

安装后，在“设备”页连接或扫描电脑助手二维码配对，允许局域网访问。电脑正常登录 B 站，手机和电脑连接同一路由器。Siri 可使用“用哔哩遥控暂停播放”“用哔哩遥控播放下一个视频”；快捷指令 App 中的“控制电脑上的哔哩哔哩”也可选择操作。

在 iPhone 的 Watch App 中安装“哔哩遥控”配套应用。手表通过 iPhone 联系电脑，需要 iPhone 可达、未被强制退出且能访问电脑所在的局域网。

## 新入口

- “收藏”标签页：读取电脑浏览器登录账号的收藏夹，搜索、点播或整夹连播。
- “播放”页 → “查看评论 / 发表评论”：查看热门 / 最新评论和楼中楼，发表评论或回复。
- 点击 UP 主名字：查看资料、投稿搜索 / 排序、合集与系列。
- 播放列表封面会自动补齐与重试，无需先手动刷新。

自动构建和界面检查通过不等于真实设备验收；Siri 识别、Watch 后台控制与真实账号评论仍需在签名安装后核对。详细范围见 [验证记录](COMMUNITY-AND-WATCH.md)。
