# 0.6.0：Windows 图标与正版影视

- Windows 可执行文件、窗口 / 任务栏、托盘和安装包使用与 iOS 一致的粉色电视图标，包含 16–256 像素的多尺寸资源。
- 发现页增加“影视”：搜索电影、电视剧和纪录片等正版内容，展示片目封面、分类、更新信息和会员标记。
- 片目详情显示正片选集，支持从头播放或指定集数开始连播；播放页保留选集、音量、清晰度、全屏等控制。
- 目录读取覆盖滚动加载的选集，排除预告与花絮。读取不完整时明确报错；会员试看结束、登录或地区限制会暂停队列。
- 此版基于已有 0.5.1 工作状态，保留首页推荐、收藏、评论、Siri、Apple Watch 以及全屏和扩展重载修复。原主工作目录未修改。

需同时更新 Windows 助手、Chrome 扩展和 iOS App。更新后在 Chrome 扩展页重新加载扩展，并刷新 B 站播放页面。会员 / 付费内容使用电脑账号已有的观看权限。

`scripts/apply-player-update.ps1` 现在同时更新 `BiliRemote.exe`（图标位于该文件）、两个应用 DLL 和扩展，并为旧文件建立备份。仅替换 DLL 无法更新资源管理器的程序图标。
