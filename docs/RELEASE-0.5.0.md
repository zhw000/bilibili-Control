# 0.5.0 首页推荐

手机新增“首页”标签，并作为打开 App 后的默认页：显示电脑 Chrome 当前登录账号在 B 站网页首页得到的推荐视频。数据来自网页首页同一个推荐接口（`/x/web-interface/wbi/index/top/feed/rcmd`），签名方式与网页一致，推荐结果随这个账号的观看记录变化。

- 双列卡片：封面、播放量、弹幕数、时长、标题、UP 主、发布时间，以及“已关注”“X万点赞”等推荐理由。横屏和 iPad 会自动增加列数。
- 下拉或点右上角“换一换”获取新一批，相当于在网页首页点一次“换一换”；滑到底部自动加载下一批，也可点“加载更多”。
- 点卡片立即在电脑播放并切到“播放”页；点 UP 主名进入其主页。
- 只显示可以遥控播放的普通视频，广告、直播和番剧卡片会被过滤。
- 电脑 Chrome 未登录时显示通用推荐，并提示登录后下拉刷新。安全验证、风控或接口变化会显示错误，不会显示成空列表。

## 已知问题

排查中发现：扩展后台发送的 POST 请求会带 `Origin: chrome-extension://…`，B 站对此返回 412，因此手机“发表评论”很可能总是提示“发送结果尚未确认”。与本次功能无关，另行修复。
