# Chrome 扩展 0.5.1：遥控全屏改为真正全屏

仅需更新 Chrome 扩展，电脑助手和 iPhone App 无需更新。

## 变化

0.4.1 起，手机上的“全屏”只打开 B 站的网页全屏，浏览器标签栏和地址栏仍然可见。0.5.1 改为真正的全屏：播放器先铺满网页，随后 Chrome 窗口进入全屏，隐藏标签栏和地址栏，视频占满整个屏幕。

0.4.0 曾出现浏览器全屏退不出来的问题：按 Esc 或网页退出按钮只退出了网页全屏，窗口仍停在全屏，需要按 F11。现在两层全屏作为一个整体进出：

- 手机关闭全屏，或在电脑上按 Esc、点播放器的退出按钮：网页全屏和窗口全屏一起退出，窗口恢复为原来的最大化 / 普通状态。
- 连播切到下一个视频（或刷新页面）时自动恢复全屏；新页面没有播放器时退出全屏并交还窗口。
- 关闭视频标签页、在全屏窗口里切到其他标签页、视频标签页离开 B 站，或在手机“设备”页换控制标签页时，窗口会恢复。
- 如果窗口在遥控前已经是浏览器全屏（例如按过 F11），扩展不会改变或恢复它。

网页不能在没有真实点击的情况下调用浏览器的全屏接口，所以这里使用 Chrome 窗口全屏配合网页全屏，效果与按 F 键全屏相同。Chrome 进入全屏时可能短暂提示按 F11 退出；按 F11 只会退出窗口全屏，再按 Esc 即可退出网页全屏。

## 更新方法

1. 在 `chrome://extensions` 重新加载“哔哩遥控 · Bili Remote”，确认版本为 **0.5.1**。
2. 刷新已打开的 B 站视频页面。

## 验证

类型检查和 99 项自动化测试通过（新增 11 项），覆盖先网页全屏后窗口全屏的顺序、手机关闭、Esc / 网页按钮退出只恢复一次、网页无响应时仍恢复窗口、下一页自动恢复及无播放器时交还窗口、不接管用户自己的 F11 全屏、关闭或切换标签页、离开 B 站，以及新页面等待播放器控件出现。实际 Chrome 中的全屏效果需在重新加载扩展后用手机现场确认。
