# 0.4.0 视频清晰度

在手机“播放”页，点倍速 / 弹幕 / 全屏下方的“清晰度”，选择电脑播放器提供的档位。页面会显示当前档位、实际画面尺寸、选中标记和网站提供的权限标签。选择“自动”后由 B 站决定播放档位。

清晰度选项读取自当前视频，不会固定显示不存在的 4K 或高帧率选项。部分档位需要登录或大会员；标签不代表当前账号一定无法使用。切换由 B 站原生菜单执行，网页未确认选中目标档位时会提示检查电脑上的登录、会员或播放器提示。切换可能短暂缓冲，画面尺寸会在新画面到达后更新。

## 更新

本次需要一起更新 Windows 助手、Chrome 扩展和 iPhone App。

- 本机助手已更新到 `E:\BiliRemote`，版本 0.4.0；旧文件备份位于 `E:\BiliRemote\backup-player-20260925-141324`，配对信息保留。
- 扩展文件位于 `E:\BiliRemote\extension`。用户已确认在 Chrome 重新加载到 0.4.0，并刷新 B 站页面。
- 新 IPA 需签名后安装，内含 Apple Watch 配套应用，重签名时也需处理 Watch 子应用及配套 Bundle ID。iOS 17+ / watchOS 10+ 要求不变。清晰度选择入口位于 iPhone，原有 Siri 和 Watch 播放控制保留。

如果清晰度页面提示更新，通常是旧助手或旧扩展仍在运行；如果没有可选项，先等视频加载完成或刷新电脑视频页。菜单只针对主播放器，不操作相关推荐的小预览。

## 安装包

- 文件名：`BiliRemote-0.4.0-unsigned.ipa`，版本 0.4.0（构建 5），大小 523,700 字节。
- SHA-256：`14cf6bbbdbce9a8414c43035409215cb74fdd45cde06b569f3b8b6c6a8a523ba`，本地校验与构建端一致。
- 先签名并安装到 iPhone，再在“设备”页连接电脑；手机和电脑需能在局域网内互通。开始播放视频后，在“播放 → 清晰度”选择档位。
- 该包保留 Siri、评论、收藏、UP 主主页和 Watch 控制。Siri 与 Watch 的真实设备运行，以及手机到真实浏览器的清晰度切换，需在签名安装后完成最终验证。
